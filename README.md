# LinkVault 🚀

LinkVault is a sleek, dark-themed bookmark and link management web application designed for direct hosting on **GitHub Pages**.

## Features ✨
- 📂 **Emoji Collections**: Organize bookmarks into customizable categories with custom icons.
- 🖼️ **Auto-Banner Matching**: Automatic dark preview headers for YouTube, Twitch, GitHub, Figma, React Docs, and Spotify.
- 🔍 **Real-Time Search**: Search saved links by title, URL, or description instantly.
- 💾 **Browser LocalStorage**: Save all links and categories persistent across page reloads.

## Quick GitHub Pages Setup 🌐

1. Upload `index.html` directly to the main root folder of your GitHub repository.
2. Go to **Settings > Pages** in your repository.
3. Under **Branch**, select `main` and `/ (root)`, then click **Save**.
4. Your website will go live automatically at: `https://JeffyBoii.github.io/LinkVault/`
